# Цифровой след инженера 2.0.0

Комплект локального плагина и исполняемого ядра для исследовательского диалога
с ИИ, анализа исходных свидетельств и преподавательского рассмотрения.
Начните с START_HERE.md. Полный паспорт — docs/Release_Guide.docx.

В архив входят 15 исходных учебных документов, извлечённые тексты, модель занятия
8, три навыка, установщик, тесты и примеры Word-отчётов. Другие занятия используют
тот же процесс: ИИ адаптирует код по соответствующему материалу и запросам студента.
Готовность материалов не объявлена результатом 24 прогонов каждого занятия.

Архитектура: локальные project hooks → SQLite с исходными байтами → исполняемые
эксперименты → фиксированное основание → смысловой ответ модели → проверка цитат
и арифметики → рассмотрение преподавателем → ведомость/апелляции/отчёты.

Это продолжение локального варианта B. Нет собственного сайта, Docker или сервера.
Для браузерного ChatGPT такой локальный механизм захвата не подтверждён. Навык
без исполнения Python и доверенных хуков не даёт автоматического журнала.

## Проверка разработчиком

Python 3.11+: `python -m pip install -r requirements.txt`.
`python -m unittest discover -s tests -v`.
`python tools/verify_release.py` проверяет контрольные суммы поставки.
`python install.py` готовит только определения хуков текущего проекта.
Доверие пользователь выдаёт в интерфейсе приложения; обход доверия не используется.

Плагин описан в .codex-plugin/plugin.json, локальный каталог —
.agents/plugins/marketplace.json. Для работы с папкой через AGENTS.md регистрация
в каталоге не обязательна. Перед командами установки плагина проверьте
`codex plugin --help`: возможности конкретной версии приложения различаются.
Публикация в аккаунте и установка у другого получателя в этом выпуске не выполнялись.

## Существенные ограничения

Смысл анализирует модель текущего чата, а не Python-эвристика. Независимость
контекста учебного ИИ и анализатора не гарантируется. Преподавательский аккаунт
проводит новый разбор импортированных исходных свидетельств.

Хеширование помогает обнаружить изменения относительно сохранённого основания.
Оно не доказывает авторство и не защищает от владельца компьютера, способного
переписать журнал и хеши. Роли локальные, не университетский SSO.

SQLite нужно хранить на локальном диске. Между аккаунтами передаются *.dt.zip
через разрешённую папку, при желании синхронизируемую Google Drive. В релизе нет
облачного сервера, настройки прав Drive, автоматической почты или записи в Платонус.
Нет фоновой службы: sync выполняется при запросе преподавателя.

Лимит в программе относится к локальным экспериментам, а не реальным токенам
или оплате подписки GPT. Исчерпание не снижает балл и не удаляет работу.
Код эксперимента выполняется локально; это не отдельная защищённая песочница.

Временное состояние прошлой незавершённой сборки не вошло в релиз. Все отчёты
проверок qa относятся к фактически восстановленной и упакованной версии.
