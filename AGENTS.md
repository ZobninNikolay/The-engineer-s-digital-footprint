# Digital Trace 2.0

Use this project as the runtime for a research dialogue, not a calculation form.
Read START_HERE.md and the appropriate skills/student/SKILL.md,
skills/reviewer/SKILL.md or skills/teacher/SKILL.md before acting.
Use the project's .venv Python after setup; otherwise use an available Python 3.11+.
Run `python dt.py --help` to inspect exact commands. All IDs must come from actual
command output; never invent session IDs, evidence, grades or command results.
Only use this project's `workspace` or explicitly authorized test folders.
Do not modify original archives or old evidence. Do not overwrite a pilot with demo data.
The student speaks in natural language; you operate JSON/CLI and produce Word files.
Never ask a student to manually copy the dialogue or calculate by hand.
Do not convert a local folder into a browser plugin claim. Installing files is not
proof of hook execution. No bypass of hook trust, no fake platform events.
When capture fails, follow docs/HOOK_DIAGNOSTICS.md and change one diagnosed cause.
No external sends/publishing, no real student records outside authorized pilot scope.
Read and update STATE.md when changing the implementation; keep test results honest.
